# Actividad 3 - Viabilidad Económica y Gestión de Riesgos

## Descripción

En esta actividad se evaluó la viabilidad económica y operativa de un proyecto de inteligencia artificial mediante el análisis de costos, beneficios, retorno de inversión (ROI) y gestión de riesgos.

Como continuación del proyecto desarrollado en las actividades anteriores, se analizó una solución de inteligencia artificial orientada a la automatización del cruce de autopartes entre AutoZone y sus proveedores, con el objetivo de reducir el esfuerzo manual requerido para identificar coincidencias entre catálogos de productos.

## Proyecto seleccionado

### Automatización del Cruce de Autopartes mediante Inteligencia Artificial

La iniciativa busca utilizar modelos de inteligencia artificial para analizar automáticamente las descripciones de productos y sugerir coincidencias potenciales entre el catálogo interno de AutoZone y los catálogos de proveedores.

Actualmente este proceso se realiza de forma manual por analistas especializados, consumiendo una cantidad considerable de tiempo y recursos.

## Objetivos

- Evaluar la viabilidad económica del proyecto.
- Identificar costos y beneficios asociados a la implementación.
- Calcular el retorno de inversión (ROI).
- Determinar el período de recuperación de la inversión (Payback).
- Identificar riesgos relevantes para el proyecto.
- Diseñar estrategias de mitigación.
- Integrar el análisis financiero con la gestión de riesgos.

## Resultados financieros

### Inversión inicial

- $450,000 MXN

### Beneficios acumulados (3 años)

- $1,536,000 MXN

### ROI

- 241.33%

### Payback

- 0.88 años (aproximadamente 10 meses)

## Principales riesgos identificados

### Riesgos críticos

- Cruces incorrectos generados por IA.
- Disminución de precisión por cambios en proveedores.
- Dependencia excesiva de la IA.
- Degradación del modelo.

### Riesgos altos

- Sesgo hacia determinados proveedores.
- Uso de información incorrecta.
- Falta de explicabilidad.
- Fallas de integración.

### Riesgos moderados

- Incremento de costos de infraestructura.
- Dificultad para justificar resultados.

## Estrategias de mitigación

Se definieron estrategias de mitigación para cada riesgo priorizado, incluyendo responsables, recursos requeridos y KPI de seguimiento.

Las principales acciones contemplan:

- Validación humana de resultados críticos.
- Monitoreo continuo del desempeño del modelo.
- Reentrenamiento periódico.
- Auditorías de calidad de datos.
- Implementación de mecanismos de explicabilidad.
- Contratos de soporte para componentes críticos.

## Conclusión

El análisis realizado demuestra que la automatización del cruce de autopartes representa una oportunidad viable para mejorar la eficiencia operativa del área. Además de mostrar un retorno de inversión atractivo, el proyecto cuenta con estrategias definidas para gestionar los riesgos identificados y aumentar las probabilidades de éxito durante su implementación.
